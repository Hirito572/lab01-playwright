## 5. Ашигласан Locator болон Assertion

Тестийн элементүүдийг олохдоо Playwright-ийн дараах locator болон assertion-уудыг ашигласан.

- `getByPlaceholder()` — Username болон Password талбаруудыг олох.
- `getByRole()` — Login, Logout зэрэг товчийг олох.
- `getByText()` — Products болон барааны нэрийг шалгах.
- `locator()` — data-test болон CSS selector ашиглан тодорхой элементийг олох.
- `toBeVisible()` — элемент харагдаж байгаа эсэхийг шалгах.
- `toHaveURL()` — хуудасны URL-ийг шалгах.
- `toHaveText()` — элементийн текстийг шалгах.

XPath-аас зайлсхийх нь веб хуудасны бүтэц өөрчлөгдөхөд тест эвдрэх эрсдэлийг багасгадаг. Харин хэрэглэгчийн харж, ашиглаж байгаа элементэд тулгуурласан locator нь тестийг илүү ойлгомжтой, засварлахад хялбар болгодог.

## 6. Codegen туршилт

Playwright Codegen ашиглан SauceDemo вебсайт дээрх хэрэглэгчийн үйлдлийг бичүүлж, автоматаар үүссэн кодтой танилцсан.

Ашигласан команд:

```bash
npx playwright codegen https://www.saucedemo.com/
```

Үүссэн кодыг өөрийн бичсэн тестүүдтэй харьцуулж, locator болон үйлдлүүдийн ялгааг ажигласан.

Нотолгоо: `screenshots/codegen.png`

## 7. Trace Viewer туршилт

Тестүүдийг Trace-тэй ажиллуулж, браузер дээр хийгдсэн үйлдлүүдийг Trace Viewer ашиглан шалгасан.

Ашигласан команд:

```bash
npx playwright test --trace on
```

Trace файлыг нээх команд:

```bash
npx playwright show-trace test-results/.../trace.zip
```

Мөн assertion-ийн хүлээгдэж буй утгыг зориудаар буруу болгож тестийг унагаан, Trace Viewer дээр алдааны шалтгаан болон тухайн үеийн хуудасны төлөвийг шалгасан. Дараа нь assertion-ийг зөв утгаар сэргээж, тестүүдийг дахин амжилттай ажиллуулсан.

Нотолгоо:

- `screenshots/trace-failure.png`
- `screenshots/trace-viewer.png`

### 8.1 Test Isolation

Playwright нь тест бүрд тусдаа Browser Context ашигладаг. Ингэснээр нэг тестийн нэвтрэлтийн төлөв болон cookie нь дараагийн тестэд нөлөөлөхгүй.

Амжилттай нэвтрэх болон сагсанд бараа нэмэх тестийн төгсгөлд Logout хийж, нэвтрэх хуудас руу буцсаныг шалгасан. Харин амжилтгүй нэвтрэх тестэд хэрэглэгч нэвтрээгүй тул Login хуудас дээр үлдсэнийг шалгасан.

## 9. Playwright ба Selenium-ийн харьцуулалт

Selenium болон Playwright нь хоёулаа веб UI автоматжуулалтын зориулалттай, үнэгүй, нээлттэй эхийн Apache 2.0 лицензтэй хэрэгслүүд юм.

Selenium нь олон жилийн турш ашиглагдсан бөгөөд Java, Python, C#, JavaScript зэрэг олон хэл дэмждэг. Playwright нь Microsoft-ийн хөгжүүлсэн орчин үеийн хэрэгсэл бөгөөд JavaScript, TypeScript, Python, Java болон C# хэл дэмждэг.

Selenium дээр элемент ачаалагдахыг хүлээхдээ ихэвчлэн explicit wait-ийг гараар тохируулах шаардлагатай байдаг бол Playwright нь auto-wait механизмыг автоматаар ашигладаг. Selenium нь браузер бүрд тусдаа WebDriver шаарддаг бол Playwright браузеруудыг нэг командаар суулгах боломжтой.

Selenium IDE нь тест бичихэд тусалдаг бол Playwright Codegen нь хэрэглэгчийн үйлдлийг бичиж код үүсгэдэг. Selenium дээр лог болон screenshot ашиглан алдааг шалгадаг бол Playwright Trace Viewer нь алхам бүрийн үйлдэл, DOM snapshot болон бусад мэдээллийг харах боломж олгодог.

Миний туршилтаар Playwright-ийн auto-wait болон Trace Viewer нь тест бичих, алдаа илрүүлэхэд илүү хялбар санагдсан.
